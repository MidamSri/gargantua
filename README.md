# Gargantua — AI Risk Intelligence + Insurance Infrastructure

> *"Credit scores measure financial trust. Gargantua measures AI trust."*

Gargantua is the institutional trust-scoring and actuarial underwriting infrastructure designed for frontier AI models and autonomous agent deployments. As AI agents gain budget authority, execute code, and manage enterprise infrastructure, Gargantua provides continuous fleet telemetry, automated synthetic red-team stress testing (3,500+ probes), standardized 300–850 AI Credit Ratings, and direct loss-indemnity insurance capacity underwritten by Gargantua Syndicate #4401 and Lloyd's of London partners.

- **🌌 3D WebGL Singularity Experience**: Real-time relativistic black hole accretion disk simulation and camera warping based on scroll progress.

## 🚀 Quick Start

### Prerequisites
- Node.js 18+
- npm / yarn / pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/MidamSri/gargantua.git
cd gargantua

# Install dependencies
npm install

# Start development server
npm run dev
```

The application will be available at `http://localhost:5173`.

### Production Build

```bash
npm run build
npm run preview
```
